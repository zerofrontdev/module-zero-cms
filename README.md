# Zero_Cms

The page builder for CMS pages, blocks and other content types (the blog's
posts): JSON content per store view, with revisions.

## Install

Requires Magento Open Source 2.4.7–2.4.9 and PHP 8.2–8.4 with the GD extension built with WebP (`php -r 'var_dump(function_exists("imagewebp"));'` says `true`; Magento's own PHP requirements cover the rest). Without WebP in GD, Zero skips its WebP image copies and serves the originals.

```bash
composer require zerofront/module-zero-cms
bin/magento setup:upgrade
bin/magento setup:di:compile           # production mode
bin/magento setup:static-content:deploy # production mode
bin/magento cache:flush
```

Composer installs `zerofront/module-zero-core` with it.

Part of [`zerofront/zero`](https://zerofront.dev), which installs the Zero theme and every Zero module at once.

## Cache

Saving in the editor and "Reset to All Store Views" both clean the page,
block or post from the full-page cache (built-in or Varnish) and the block
cache through the entity's cache tags (`Model/Content/CacheRefresh`).
`Model/Content/Repository` itself is storage only: code that writes or
deletes content through it refreshes the cache.
